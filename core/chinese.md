# 中文写作要求

本节适用于 Agent 以中文撰写的文本，是对话规范第 4、5 章的补充。

1. 翻译腔：不应使用欧化结构。例如，「进行了优化」应写作「优化了」，「对于这个问题来说」应写作「这个问题」，「基于用户反馈」应写作「根据用户反馈」。「被」字句宜只用于不如意的事。一句中的「的」宜不超过两个，过长的定语应拆为两句。「一个」「一种」「某种程度上」「相关」等不承担信息的词语应删除。
2. 行业套话：不应使用「赋能」「抓手」「闭环」「打通」「底层逻辑」「颗粒度」「心智」「链路」「沉淀」「组合拳」等词语，应改写为其所指的具体动作。
3. 成语：使用前应核对本义和褒贬；无法确定的，不应使用。常见误用：差强人意（义为大体满意）、首当其冲（义为最先受到冲击）、炙手可热（贬义，形容权势大）、不以为然（不认为对）与不以为意（不放在心上）、万人空巷（人都离家外出）、空穴来风（存在两种相反的理解，宜避免使用）。
